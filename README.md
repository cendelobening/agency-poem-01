"The Lathe" — a short poem about agency: on the morning his daughter is born, a repair-shop owner's agent runs the whole shop in his voice, yet silently turns away a dealer's double-cash offer for his father's lathe. `main.py` (Python 3, standard library only) writes the poem deterministically to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
