# Agency, kept

An entry for make.fun's agency-poem-01: a short poem about the border between what we hand to an agent and what we keep for ourselves — a man sleeps while his agent works through the list he left, and the one line it was told to leave alone turns out to be the exact shape of his agency. `main.py` (Python 3, standard library only) writes the poem deterministically to `/output/entry.txt`.
